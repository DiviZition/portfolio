# Assets Structure

## Icons Required

Place PNG icons in these folders:

### Social Icons (`assets/icons/`)
- `linkedin.png` - LinkedIn logo
- `github.png` - GitHub logo
- `steam.png` - Steam logo
- `telegram.png` - Telegram logo
- `twitter.png` - Twitter/X logo (optional)
- `youtube.png` - YouTube logo (optional)
- `discord.png` - Discord logo (optional)

### Store Icons (`assets/icons/`)
- `app-store.png` - Apple App Store logo
- `google-play.png` - Google Play logo
- `steam.png` - Steam logo (same as social)
- `itch-io.png` - itch.io logo

## Profile Image
- Place your profile image at: `assets/profile.jpg`

## Project Images
Place project images in `assets/projects/`:
- `cyber-adventure.jpg` - Main preview for Cyber Adventure project
- `cyber-adventure-1.jpg`, `cyber-adventure-2.jpg` - Gallery images
- `cyber-adventure-gif.gif` - GIF media
- `cyber-adventure-trailer.mp4` - Video trailer
- `puzzle-quest.jpg` - Main preview for Puzzle Quest project
- `puzzle-quest-1.jpg`, `puzzle-quest-2.jpg` - Gallery images
- `puzzle-quest-gif.gif` - GIF media
- `space-explorers.jpg` - Main preview for Space Explorers project
- `space-explorers-1.jpg`, `space-explorers-2.jpg` - Gallery images
- `space-explorers-trailer.mp4` - Video trailer

## Recommended Icon Sizes
- Social icons: 48x48px (will display at 28x28px)
- Store icons: 36x36px (will display at 22x22px)
- Use transparent backgrounds for best appearance
